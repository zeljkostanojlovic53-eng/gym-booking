# Gym Booking API

A REST API for running a gym. Members buy a membership plan, book group classes that have limited spots, join waitlists, and book personal training sessions with trainers.

## Planned features

- Registration and login with JWT, with the roles ADMIN, TRAINER and MEMBER
- Membership plans with monthly class credits
- Class schedule with rooms, trainers and capacity
- Booking and cancellation with credit refund rules
- Waitlist with automatic promotion when a spot opens
- Personal training bookings
- Email notifications, reminders and admin reports

## Tech stack

Java 21, Spring Boot, Spring Security (JWT), Spring Data JPA and Hibernate, PostgreSQL, Flyway, Docker, JUnit 5, Testcontainers, GitHub Actions
